# Usage Guide

## Uploading
Linux:
```
./scripts/bash/upload.sh file.txt /remote/path/
```

Windows:
```
.\scripts\powershell\Upload-SFTP.ps1 -LocalFile file.txt -RemotePath /remote/path/
```

Python:
```
python3 scripts/python/upload.py file.txt /remote/path/
```

## Syncing (Linux)
```
./scripts/bash/sync.sh
```
